# MollowLauncher 2.0 — Minecraft-лаунчер (Emerald UI)

Python 3.10+ · PyQt6 · Windows 10/11. Офлайн-аккаунты, сборки (инстансы), Vanilla и Fabric,
мод-менеджер с каталогом Modrinth, обложки, 4 темы.

## Где хранятся данные
`C:\Users\<имя>\AppData\Roaming\.MollowLauncher` — сборки, миры, моды, библиотеки, Java, настройки.
Данные старой версии (MMCLite, папка `data` рядом с программой) при первом запуске переносятся туда автоматически.
Другое место можно задать переменной среды `MOLLOW_HOME`.

## Запуск из исходников
`run.bat` или `pip install -r requirements.txt` → `python main.py`.
Если pip ругается на SSL: `pip install pip-system-certs --trusted-host pypi.org --trusted-host files.pythonhosted.org`.

## Установщик
`build_installer.bat` — одним кликом (файл только на английском и с CRLF — иначе cmd.exe ломает строки): ставит зависимости,
собирает программу в папку `dist\MollowLauncher` (режим onedir: запускается мгновенно, ничего не распаковывает во временную папку,
реже ругается антивирус) и делает `installer_output\MollowLauncher_Setup.exe` — один файл, которым можно делиться: мастер на русском
с фирменными картинками, по умолчанию ставится в `C:\MollowLauncher` (папку можно сменить), ярлыки, удаление через «Приложения»,
обновление поверх старой версии (запущенный лаунчер закрывается сам); при удалении спросит, стирать ли игровые данные.
Для установщика нужен Inno Setup 6 — скрипт попробует поставить его сам через winget. Права администратора не нужны.
Версия задаётся в `launcher/version.py`. Иконка рисуется скриптом `tools\make_icon.py`.

## Выкладка на GitHub (автоматическая сборка релиза)
1. Создайте пустой репозиторий на github.com и залейте проект (содержимое папки `MollowLauncher`, внутри уже есть `.gitignore` и `.github/workflows/release.yml`):
   `git init && git add . && git commit -m "MollowLauncher" && git branch -M main && git remote add origin https://github.com/<вы>/<репозиторий>.git && git push -u origin main`
2. Поднимите версию в `launcher/version.py` (например, `2.0.2`), закоммитьте и выпустите релиз тегом:
   `git tag v2.0.2 && git push origin v2.0.2`
3. GitHub сам соберёт программу и установщик на Windows-сервере и приложит `MollowLauncher_Setup.exe` к Release
   (вкладка Releases). Ссылка на всегда свежую версию:
   `https://github.com/<вы>/<репозиторий>/releases/latest/download/MollowLauncher_Setup.exe`
   Ручной запуск без тега — вкладка Actions → Release → Run workflow (установщик будет в Artifacts).

Установщик не подписан цифровой подписью, поэтому Windows SmartScreen при первом запуске может показать «Неизвестный издатель»:
«Подробнее» → «Выполнить в любом случае».

## Если что-то упало
Необработанные ошибки больше не закрывают лаунчер: внизу появится уведомление, а подробности запишутся в
`%APPDATA%\.MollowLauncher\launcher.log` (при аппаратных сбоях — `fault.log`). Пришлите этот файл разработчику.

## Страницы
- **Главная** — приветствие, поиск, статистика, избранное и недавно запущенные сборки.
- **Библиотека** — все сборки, поиск, фильтр (все / избранные / загрузчик), сортировка, «Создать сборку».
- **Создать сборку** — версии Minecraft (релизы/снапшоты/alpha/beta), загрузчик, нужная Java,
  «Только создать» или «Создать и установить» с реальным прогрессом и отменой.
- **Моды** — вкладка «Моды» в настройках сборки (шестерёнка на карточке): поиск, включение/выключение (файл переименовывается в `.jar.disabled`,
  не удаляется), добавление .jar, информация о моде, удаление только по явной кнопке.
- **Аккаунты**, **Настройки** (тема, память и размер окна для всех сборок, Java, поиск/скачивание Java).
- **Экран запуска** — обложка сборки, этапы, прогресс, скорость, отмена, логи, завершение игры.

## Карточка сборки
Клик — выбрать, двойной клик/«Играть» — запуск, шестерёнка — настройки, звезда — избранное,
правый клик — меню (обложка, папка, моды, копия, удаление). Обложка хранится в `instances/<имя>/cover.png`.

## Архитектура
`launcher/` — логика без Qt-виджетов: `launch.py` (запуск), `mojang.py`, `fabric.py`/`loaders.py`
(реестр загрузчиков: Forge/NeoForge добавляются новым классом + `register()`), `java.py`, `net.py`
(скачивание, статистика, отмена), `mods.py`, `library.py`, `instance.py`, `config.py`, `covers.py`.
`launcher/ui/` — интерфейс: `theme.py` (палитры и QSS), `icons.py`, `widgets.py`, `cards.py`,
`pages/*`, `main_window.py`. Долгие операции идут в `QThread` (`ui/workers.py`).

## Без отдельных окон
Настройки сборки — страница внутри лаунчера, ник вводится прямо на странице «Аккаунты»,
подтверждения (удаление, Java, закрытие при запущенной игре) показываются поверх главного окна.
Исключение — системные окна выбора файла (обложка, .jar, java), их рисует сама Windows.

## Время и запущенные игры
- На главной: «Время в играх» (сумма по всем сборкам) и «Время в лаунчере». На карточке — время в этой сборке.
  Время копится по минутам и сохраняется при закрытии, даже если лаунчер закрыли вместе с игрой.
- Пока игра идёт, на карточке кнопка «Остановить игру», а в боковой панели — «Игра запущена»:
  по ней можно вернуться к окну запуска и логам из любой страницы.

## Моды из Modrinth (прямо в лаунчере)
Шестерёнка на карточке → вкладка «Моды» → **«Найти моды»**: каталог Modrinth с поиском, сортировкой,
иконками и кнопкой «Установить». Подбирается версия мода под Minecraft и загрузчик сборки (релиз важнее беты),
обязательные зависимости (например, Fabric API) ставятся автоматически. Установленные моды помечены
«Установлен». «Из файла…» — добавить `.jar` с компьютера. Для Vanilla моды недоступны.
CurseForge не подключён: ему нужен личный API-ключ.
